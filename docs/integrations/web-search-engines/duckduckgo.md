# DuckDuckGo

https://duckduckgo.com/

## Maven 依存関係

```xml

<dependency>
    <groupId>dev.langchain4j</groupId>
    <artifactId>langchain4j-community-web-search-engine-duckduckgo</artifactId>
    <version>${latest version here}</version>
</dependency>
```
