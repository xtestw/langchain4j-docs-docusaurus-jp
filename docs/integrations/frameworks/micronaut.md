# Micronaut

[Micronaut](https://micronaut.io/) は、設定管理と LangChain4j API の依存性注入を提供する LangChain4j 統合モジュールを提供しています。

Micronaut の [LangChain4j 統合](https://micronaut-projects.github.io/micronaut-langchain4j/latest/guide/) には次の機能が含まれます：

- 各プロバイダー向けの `ChatModel` および `StreamingChatModel` の[設定と依存性注入](https://micronaut-projects.github.io/micronaut-langchain4j/latest/guide/#chatModels)
- 一般的な埋め込みストアプロバイダー向けの [Embedding Stores](https://micronaut-projects.github.io/micronaut-langchain4j/latest/guide/#embeddingStores) の簡易セットアップ
- [Micronaut Test Resources](https://micronaut-projects.github.io/micronaut-test-resources/latest/guide/) と Testcontainers との統合による、コンテナ化された LangChain4j テスト
- Tools と Language Models の統合を簡素化する宣言的な `@AiService`

詳細は [Micronaut LangChain4j 統合](https://micronaut-projects.github.io/micronaut-langchain4j/latest/guide/) のドキュメントを参照してください。
